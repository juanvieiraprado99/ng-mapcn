# ng-mapcn troubleshooting

| Symptom                                                                                                                              | Cause                                                                                                                                                                                                                                                  | Fix                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Map area is blank or has zero height                                                                                                 | `<ng-map>` fills its parent (`width/height: 100%`) and the parent has no height. Until the container has a size, initialization waits and the loader overlay stays                                                                                     | Give the parent an explicit height (`height: 400px`, `h-screen`, flex/grid sizing)                                                                                                                                                                                                                                                                                               |
| Popups or tooltips look unstyled, with a white box and arrow                                                                         | The global `.maplibregl-popup-*` overrides are missing                                                                                                                                                                                                 | Add them to the global stylesheet (below), or run `ng add ng-mapcn`, which appends them                                                                                                                                                                                                                                                                                          |
| Controls, attribution or markers are mispositioned and the map looks broken                                                          | `maplibre-gl.css` is not loaded                                                                                                                                                                                                                        | Add `node_modules/maplibre-gl/dist/maplibre-gl.css` to `styles` in `angular.json`, or `@import 'maplibre-gl/dist/maplibre-gl.css'` in global styles                                                                                                                                                                                                                              |
| Theme tokens, popup cards or tooltip pills have no styling (npm install)                                                             | The ng-mapcn stylesheet is not loaded                                                                                                                                                                                                                  | In global `styles.scss`: `@use 'ng-mapcn/src/lib/styles/index' as *;` and `@use 'ng-mapcn/styles.scss' as *;`                                                                                                                                                                                                                                                                    |
| `NullInjectorError` for `MapContextService` (or `MarkerContextService`)                                                              | A child component is outside `<ng-map>`, or a `ng-marker-*` component is outside `<ng-map-marker>`. Both services are component-scoped, not root                                                                                                       | Move the child inside the right parent                                                                                                                                                                                                                                                                                                                                           |
| Custom sources/layers vanish after toggling light/dark                                                                               | A theme change calls `setStyle`, which drops all custom sources and layers                                                                                                                                                                             | Create them in an `effect` gated on `ctx.map()` and `ctx.isLoaded()`; the effect re-runs when the gate reopens. See the custom layer recipe                                                                                                                                                                                                                                      |
| MapLibre errors when adding a source or layer                                                                                        | Layer code ran before the style was ready                                                                                                                                                                                                              | Gate on `ctx.isLoaded()`, not on `ctx.map()` alone                                                                                                                                                                                                                                                                                                                               |
| Viewport jitters or loops with `[viewport]` + `(viewportChange)`                                                                     | Rebuilding `viewport` with different values than the map reports, or mutating it                                                                                                                                                                       | Bind `viewport.set($event)` directly. The map already skips syncing while it is moving and does not re-emit programmatic `jumpTo` updates                                                                                                                                                                                                                                        |
| Data does not update when the array changes                                                                                          | Layer components push `data` / `coordinates` only when the reference changes                                                                                                                                                                           | Replace the array/object (`signal.set([...])`) instead of mutating it                                                                                                                                                                                                                                                                                                            |
| Hover highlight on `ng-map-geojson` does nothing                                                                                     | `fillHoverPaint` needs `promoteId` and `interactive`                                                                                                                                                                                                   | Set `promoteId` to a unique feature property and `[interactive]="true"`                                                                                                                                                                                                                                                                                                          |
| A hover popup disappears when the cursor moves into it                                                                               | The popup captures the pointer, so the layer fires `mouseleave`                                                                                                                                                                                        | Add `className="ng-popup-passthrough"` (and `[closeOnClick]="false"`) to the `ng-map-popup`. On a plain `styles.css` without `ng add`, copy the `.ng-popup-passthrough` rule from `_utilities.scss`                                                                                                                                                                              |
| A `class` on `ng-marker-popup`, `ng-map-popup`, `ng-marker-tooltip`, `ng-marker-content` or `ng-map-controls` has no effect          | Their content is portaled into elements MapLibre owns, so the Angular host is not what you see                                                                                                                                                         | Use the `className` input, which lands on `.ng-popup-card`, `.ng-tooltip-pill`, `.ng-marker-content` or `.ng-controls`                                                                                                                                                                                                                                                           |
| `featureClick` / `featureHover` / `pointClick` handler does not compile after typing `data` with an interface                        | The components are generic: the payload is `MapGeoJSONEvent<P>` / `ClusterPointClickEvent<P>`, and an interface is not assignable to the default `Record<string, unknown>`                                                                             | Type the handler with the same argument, e.g. `MapGeoJSONEvent<CountryProperties>`                                                                                                                                                                                                                                                                                               |
| Nothing is drawn for `[progress]` on `ng-map-route`                                                                                  | `progress` only feeds the children                                                                                                                                                                                                                     | Add `<ng-route-progress />` inside the route                                                                                                                                                                                                                                                                                                                                     |
| Changing `anchor`, `beforeId` or `closeOnClick` has no effect                                                                        | These are applied at creation only                                                                                                                                                                                                                     | Recreate the element (for example with `@if` or a changing `track` key)                                                                                                                                                                                                                                                                                                          |
| `maplibre-gl` build/type errors, missing `GeoJSON` types                                                                             | Wrong `maplibre-gl` major, or `@types/geojson` missing                                                                                                                                                                                                 | Use `maplibre-gl ^6.11.2` (earlier majors do not match; `ng add` warns and keeps an older pin) and, for `ng add` copies only, `@types/geojson` (`ng add` adds it; the npm package already depends on it)                                                                                                                                                                         |
| Map throws on creation                                                                                                               | MapLibre v6 requires WebGL2                                                                                                                                                                                                                            | Handle `(mapError)`; the constructor throws a `GPUInitializationError` when WebGL2 is unavailable                                                                                                                                                                                                                                                                                |
| A layer is missing and `mapError` reports "already exists" or "non-existing layer"                                                   | Two layer components share an `id`, or `beforeId` names a layer that is not in the style                                                                                                                                                               | Give each component a unique `id`; check `beforeId` against the basemap. The failing component skips itself and the rest of the page keeps working                                                                                                                                                                                                                               |
| `Worker failed to load` in the console, worker 404, or the map never loads                                                           | `<ng-map>` loads `maplibre-gl-worker.mjs` (which imports `maplibre-gl-shared.mjs`) from `<base href>` and the files are not there, or an older ng-mapcn relied on MapLibre's default worker location, which breaks under `ng serve`                    | Add both files as `assets` in `angular.json` (glob, `input: node_modules/maplibre-gl/dist`, `output: /`) and update ng-mapcn. For a CDN or `deployUrl`, call MapLibre's `setWorkerUrl(...)` before the first map is created; `<ng-map>` keeps it                                                                                                                                 |
| SSR: errors touching `window` or the map                                                                                             | The map is created in `afterNextRender`, and children gate on the map signal, so the library is SSR-safe                                                                                                                                               | Enable hydration (`provideClientHydration`). If a server build complains about `maplibre-gl`, mark it external for the server (`externalDependencies: ["maplibre-gl"]`) or add `ngSkipHydration` to the host of `<ng-map>`. Expect a one-time basemap swap after hydration in dark mode, because the theme resolves to `light` on the server; set `theme` explicitly to avoid it |
| Tests: `<ng-map>` still uses the real `maplibre-gl` (WebGL errors in jsdom, `vi.mock` has no effect, `fakeRegistry` stays empty)     | Vitest loads `ng-mapcn` from `node_modules` as an external module, which imports the real `maplibre-gl` before the mock applies                                                                                                                        | Add `test: { server: { deps: { inline: [/ng-mapcn/] } } }` to the Vitest config used by the test target (`runnerConfig`). The regex also covers `ng-mapcn/testing*`, so the fake stays a single module instance                                                                                                                                                                  |
| Tests: `Cannot find module '@angular/cdk/testing'` (or `@angular/cdk/testing/testbed`) when importing `ng-mapcn/testing/harness`     | `@angular/cdk` is an optional peer dependency of ng-mapcn and the harness entry point imports it                                                                                                                                                       | `npm install --save-dev @angular/cdk` (same major as Angular). `ng-mapcn/testing` and `ng-mapcn/testing/maplibre` work without it                                                                                                                                                                                                                                                |
| Tests: `renderMap()` returns `map: undefined` and `getFakeMap()` throws "has not created its map"                                    | The container has zero size in jsdom, or `size: null` was passed                                                                                                                                                                                       | Keep the default size (400x300) or call `setMapSize({ width, height })`; call `resetMapTesting()` in `afterEach`                                                                                                                                                                                                                                                                 |
| Tests: `loadMap()` / `reloadStyle()` throw "cannot wait out the style debounce", or `advanceTimers` throws while fake timers are off | `loadMap()` waits 100 ms for the style debounce. With fake timers on and no `advanceTimers` that timer never fires, so the helpers throw right away instead of hanging; `advanceTimers` with `vi.advanceTimersByTime` throws while fake timers are off | Pair them: `vi.useFakeTimers()` with `configureMapTesting({ advanceTimers: (ms) => vi.advanceTimersByTime(ms) })`, and reset to `advanceTimers: null` plus `vi.useRealTimers()` in `afterEach`                                                                                                                                                                                   |
| Tests: `NG0100 ExpressionChangedAfterItHasBeenChecked` (or no update) after assigning a host property following `renderMap()`        | In zoneless apps (the Angular default; test setups without zone.js) a plain assignment marks nothing for check, so `detectChanges()` skips the host                                                                                                    | Assign through `update(fixture, props)`, which marks the host for check; or call `fixture.changeDetectorRef.markForCheck()` after `fixture.componentInstance.x = ...`, as in any zoneless Angular test; or pass a signal in `hostProps` and `.set()` it                                                                                                                          |
| Tests: `TestBed already instantiated` on the second `renderMap()`                                                                    | `renderMap()` configures `TestBed`, which can be configured once per test                                                                                                                                                                              | Call it once per test; render several maps in one template (`fakeRegistry.maps` holds them all)                                                                                                                                                                                                                                                                                  |
| Tests: `ng add` copy has no `ng-mapcn/testing`                                                                                       | The schematic copies the component sources only, not the testing files                                                                                                                                                                                 | Install the `ng-mapcn` npm package as a dev dependency for the fake, helpers and harnesses                                                                                                                                                                                                                                                                                       |

## Keyboard and accessibility

- Popups close on Escape from inside the card (`ng-map-popup` and `ng-marker-popup`). The event is stopped, so a host dialog or overlay does not also close. `ng-marker-popup` returns focus to its marker.
- A marker with `ng-marker-popup` gets `role="button"` and `aria-haspopup="dialog"` (unless you set them) and is focusable through MapLibre. `aria-expanded` follows its popup (`true` while open, whatever opened or closed it) and, while open, `aria-controls` names the popup card (`.ng-popup-card`, given a generated id). A marker whose content has its own button gets no `aria-expanded` (not allowed without a role). Name it with an `ng-marker-label`, an `aria-label` on your content or the `ariaLabel` input of `ng-map-marker`.
- A `<button>` or link inside `ng-marker-content` is the keyboard target: the marker element then gets no `role="button"` (no axe `nested-interactive`).
- Markers with `(markerClick)` are keyboard operable: `role="button"`, `tabindex="0"`, Enter/Space emit `markerClick`. Draggable markers move with the arrow keys (Shift for a larger step) and emit `dragEnd`. Static markers without handlers stay out of the tab order. Set `ariaLabel` for a name (interactive markers with no text are named "Map marker", `labels.marker`).
- `ng-marker-tooltip` opens on hover and on keyboard focus of the marker (the marker becomes a tab stop); Escape or blur closes it. Touch devices have no hover, so do not put essential content in it.
